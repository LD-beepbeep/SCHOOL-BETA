# Groq Notes Chat Setup

This feature is optional and disabled by default.

## 1) Create a Groq API key
1. Open https://console.groq.com/keys
2. Create an API key.
3. Copy the key (it starts with `gsk_...`).

## 2) Enable Notes AI inside Student OS
1. Open **Settings**.
2. Go to **Notes AI (Optional)**.
3. Paste your API key in **Groq API Key**.
4. Pick a **Default Chat Model**.
5. Turn on **Enable Groq Notes Chat**.

When this toggle is OFF, the notes chat icon is fully hidden.

## 3) Use it in Notes
1. Open the **Notes** tab.
2. Click the chat icon in the notes toolbar.
3. Choose a model in the chat header (you can switch per chat).
4. Ask your question about the current note.

## Supported model presets
- `llama-3.1-8b-instant`
- `llama-3.3-70b-versatile`
- `mixtral-8x7b-32768`
- `gemma2-9b-it`
