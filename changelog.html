What's New in Student OS

A full history of every update, fix, and improvement.

v2.0.0 Latest Major June 2026
New Features
  • Login screen redesigned — two-card layout with Sign In and Guest Mode side by side. Much cleaner first impression.
  • GitHub OAuth — sign in with your GitHub account in addition to Google and email.
  • Guest Mode — use all features without an account; data saves to local storage on the device.
  • Onboarding flow — new users are guided through theme selection and display name setup. Restartable from Settings any time.
  • GeoGebra Graphing Calculator — a new Graphing tab in the Calculator section embeds the full GeoGebra suite for free.
  • Pomodoro session statistics — total sessions completed, daily streak, and all-time best streak, displayed below the timer.
  • Brain Dump inbox — a raw textarea at the top of the Dashboard. Hit "Sort Later" to save the contents as a new note instantly.
  • Notes reading time — live word count and estimated reading time shown below the note title as you type.
  • Offline indicator — a subtle badge in the sidebar turns red with a warning when the connection drops.
  • Privacy Policy — a full privacy.html page accessible from the login screen and About section.
  • Changelog — this page, plus an in-app modal accessible from About. A "What's new" banner appears once after upgrades.
  • Multiple task lists — create named lists (Schoolwork, Hobbies, etc.) with tab switching (patches66).
Improvements
  • In-app modal engine — every native browser confirm / alert / prompt dialog replaced with styled in-app modals that match the glassmorphism theme.
  • Light theme contrast — backgrounds now have subtle depth; white-on-white modal text is fixed; all inputs and dropdowns are legible.
  • AI Notes sidebar — rebuilt as a right-side slide-in panel with Groq + Gemini support, quick-prompt buttons, and API key sync to Firestore (patches65 / patches66).
  • Whiteboard brush — brush colour now auto-inverts when the canvas background changes (light canvas = dark brush, dark canvas = light brush).
  • Mind-map overhaul — drag-and-drop nodes, double-click to edit, right-click context menu, 5 px drag threshold to prevent micro-tremor moves (patches57).
  • Flashcard star button — added to both the study view header and every row in the card list (patches58).
  • Whiteboard appearance settings — default background, pen colour, and grid-on-load moved to the correct Settings tab (patches62).
  • Routine modal — now scrollable on small screens (patches62).
Bug Fixes
  • Flashcard dashboard count — count was reading from a stale cache, showing wrong values (115 → 67 → 68 for the same deck). Now a live total from Firestore.
  • Pomodoro settings panel — clicking the gear icon inside the focus view did nothing. Event listener restored and a fallback button injected if the primary target is absent.
  • Formula block colour — the worksheet formula block was highlighted in accent blue. Now uses the same neutral glass colour as every other block (patches60 – patches63).
  • Duplicate star buttons — patches58 and patches56 were both injecting a star button on each flashcard row. patches59 deduplicates them.
  • Whiteboard settings duplication — whiteboard rows were appearing in the Widgets settings tab and the Appearance tab simultaneously. Aggressive DOM cleanup in patches59 – 62 resolves this.
  • Task list "New List" native prompt — patches66 used the browser's native prompt() dialog. Now replaced with the styled in-app prompt modal.
  • Settings sync — short break, long break, sessions before long break, grade scale, week start, and exam warning days were not restoring correctly when settings opened (patches64).
  • Marker highlight under text — the highlighter tool in Notes handwriting mode now renders on the canvas layer below the text layer (patches65).
Removed
  • Mistral and Gemma model options removed from the AI assistant — both are discontinued (patches65).
